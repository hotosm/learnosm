# Archive: old staging site (Nick-Tallguy.github.io)

Until 2026 the LearnOSM translation staging site was <https://nick-tallguy.github.io/en/>,
built from <https://github.com/Nick-Tallguy/Nick-Tallguy.github.io> and updated nightly
from Transifex by Nick Allen's `tx-10pc_pull_git_push.sh`. It has been replaced by
<https://staging.learnosm.org/en/> (see the main `README.md`).

Kept for reference:

- `tx-10pc_pull_git_push.sh`: the old nightly script. Its Transifex config is now `.tx/config`.
- `wiki/`: the repo's GitHub wiki (translator instructions, language notes, notes on the
  `_posts` folder), last edited in 2017.
