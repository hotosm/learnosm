#The site layout  

The text that you see on any of the guides / modules within LearnOSM is contained within a file in the **_posts** folder.  

###_posts  
Contains folders in the two letter iso 639-1 format - **en, de, es** etc.. If everything in terms of translation is up to date, each language folder will contain identical folders and files, eg.  

**English**  
    /_posts/en/beginner/0200-12-31-beginner.md  
    /_posts/en/beginner/0200-12-29-introduction.md  
    /_posts/en/beginner/0200-12-27-start-osm.md  
    /_posts/en/beginner/0200-12-23-id-editor.md  
    /_posts/en/beginner/0200-12-05-glossary.md  
    /_posts/en/beginner/0200-12-03-moving-forward.md
